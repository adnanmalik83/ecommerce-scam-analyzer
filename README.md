# 🛡️ E-Commerce Counterfeit & Scam Site Analyzer

An automated, intelligent web platform designed to protect consumers and digital brands from e-commerce fraud, phishing vectors, and counterfeit retail networks. Built as an innovative asset mapping to the **UK Global Talent Visa (Digital Technology)** architecture path.

## 🚀 Key Innovation Mechanics
This application goes beyond basic static blacklists. It utilizes a dynamic **Heuristic Risk-Scoring Engine** to analyze target stores in real-time across critical cryptographic and registry indicators:
* **Registry Cryptography Logs:** Automatically queries global WHOIS servers to evaluate domain longevity and operational age metrics.
* **Structural Text Analytics:** Uses layout DOM parsing via `BeautifulSoup4` to crawl text assets for predatory pricing hooks and high-pressure social engineering keywords.
* **Compliance Assessment:** Audits underlying network structures to verify the presence of mandatory digital legal infrastructure (Privacy Policies and Terms of Service).

## 🛠️ Technology Stack
* **Language:** Python
* **Frontend Web Framework:** Streamlit
* **Data Extraction Engines:** BeautifulSoup4, Requests, Python-Whois, TLDExtract

## 📦 How To Run the Application Locally
To launch this security dashboard on your system, execute the following commands in your terminal:

```bash
# Clone the repository assets
git clone https://github.com/adnanmalik83/ecommerce-scam-analyzer.git

# Install the underlying package frameworks
pip install streamlit requests beautifulsoup4 tldextract python-whois

# Launch the visual analytics engine
python -m streamlit run app.py
```
